# QQ / 微信评论推送

通过 QQ 官方机器人和微信 iLink 接收 WordPress 新评论通知，并在聊天中审核、回复评论。

作者：[老孙](https://www.imsun.org/) · [下载安装包](https://github.com/jkjoy/wordpress-comment-push/releases/latest)

## 功能

- 支持 QQ 私聊、QQ群、频道及微信通知，各渠道可独立开启。
- 可选择通知待审核、已通过的新评论，默认不通知管理员自己的评论。
- 通知包含文章、评论编号、状态、评论者和内容摘要，可附文章链接。
- 通过已授权的 QQ / 微信会话查看、审核、回复评论，或管理垃圾评论及回收站。
- 提供测试通知、运行状态和 WordPress 后台在线更新。

## 安装

要求 WordPress 6.4+、PHP 8.0+。所用渠道需能访问官方 HTTPS 接口，在线更新需能访问 GitHub；QQ 自动绑定和评论管理还需启用 PHP sodium 扩展。

从 [Releases](https://github.com/jkjoy/wordpress-comment-push/releases/latest) 下载 **`comment-push.zip`**，在 WordPress「插件 → 安装插件 → 上传插件」上传并启用。

后台「评论推送」菜单分为五页：

| 页面 | 用途 |
| --- | --- |
| 通知设置 | 选择评论状态、管理员评论和文章链接等通知规则 |
| QQ机器人 | 配置凭证、接收目标、回调绑定及 QQ 通知开关 |
| 微信连接 | 扫码登录、同步绑定接收人及微信通知开关 |
| 评论管理 | 开启 QQ / 微信管理并查看授权身份 |
| 运行状态 | 发送测试通知，查看接收器和最近处理结果 |

通知和评论管理默认关闭，配置后需分别开启并保存。

## QQ 配置

1. 在 [QQ 开放平台](https://q.qq.com/) 创建机器人并开通对应场景权限。
2. 在「QQ机器人」填写 AppID、AppSecret，选择私聊、群聊或频道并保存。
3. 设置接收目标：私聊用用户 OpenID，群聊用群 OpenID，频道用子频道 ID，不能填写普通 QQ 号或群号。私聊和群聊也可按下方步骤自动绑定。
4. 开启 QQ 评论通知并保存，到「运行状态」发送测试通知。

自动绑定与评论管理需要**公网 HTTPS 回调地址**。将「QQ机器人」显示的完整回调地址配置到 QQ 开放平台，私聊订阅 `C2C_MESSAGE_CREATE`，群聊订阅 `GROUP_AT_MESSAGE_CREATE`。在后台生成绑定码后，向目标会话发送 `绑定通知 CODE`；群聊需 @机器人。绑定码 10 分钟内有效，只能使用一次，绑定后仍需手动开启通知或管理。

QQ群中，发送绑定命令的账号是唯一管理人；如需更换管理人，请重新生成绑定码，由新管理人发送绑定命令。频道仅支持通知，且需其他程序维持机器人 WebSocket 在线。

AppSecret 留空保存会保留已有密钥。更换凭证或接收目标后需重新授权评论管理。机器人需已添加好友或入群；若带链接的通知发送失败，可关闭文章链接后重试。

## 微信配置

1. 在「微信连接」获取二维码，用微信扫码确认；如提示验证码，在同页提交。
2. 点击检查登录状态。登录后向机器人发送一条消息，再在后台同步接收人。
3. 选择并绑定接收人，开启微信通知并保存，到「运行状态」发送测试通知。

如提示会话失效，先给机器人发送消息后重新同步，必要时重新扫码。退出或重新登录微信后需重新绑定并授权评论管理。

## 通过机器人管理评论

完成接收人绑定后，在「评论管理」开启对应渠道的管理开关并保存。命令按保存时的 WordPress 管理员权限执行，回复也使用该管理员身份。管理和通知可独立开启。

QQ 私聊仅允许已绑定接收人操作；QQ群仅允许绑定的管理人操作，发送命令时需 @机器人。QQ 命令通过官方回调接收，微信命令通过下方接收器处理。

**命令与评论编号之间有空格**，例如 `通过评论 123`。将 `ID` 替换为通知中的评论编号，也可先发送 `待审评论` 查询。

| 命令 | 用途 |
| --- | --- |
| `评论帮助` | 查看命令说明 |
| `待审评论 [页码]` | 查看待审核评论，页码可省略 |
| `查看评论 ID` | 查看指定评论 |
| `通过评论 ID` | 通过审核 |
| `驳回评论 ID` | 设为待审核 |
| `垃圾评论 ID` | 标记为垃圾评论 |
| `删除评论 ID` | 移入回收站 |
| `恢复评论 ID` | 恢复回收站中的评论 |
| `回复评论 ID 内容` | 发布回复，例如 `回复评论 123 谢谢你的反馈。` |

回复前需先通过该评论。仅执行本次启用管理后、5 分钟内发送的新命令，处理结果会回复到授权会话。

### 微信持续接收

默认通过 WP-Cron 检查微信命令，依赖站点访问，无访客时可能延后；禁用 WP-Cron 的站点需配置外部计划任务或独立接收进程。

需要持续接收时，在 `wp-config.php` 载入 `wp-settings.php` 之前加入：

```php
define('WPCPUSH_RECEIVER_MODE', 'worker');
```

然后在 WordPress 安装目录，使用与站点相同的 PHP 配置运行并保持进程：

```console
php wp-content/plugins/comment-push/worker.php
```

先完成微信绑定并开启评论管理，再启动接收。无需保持后台页面打开，可在「运行状态」查看心跳和处理结果。

## 在线更新与卸载

1.2.0 起支持在「插件 → 已安装插件」或「仪表盘 → 更新」中在线升级，也可启用自动更新。1.1.1 及更早版本需先上传最新 `comment-push.zip`，选择替换已安装版本，之后即可在线更新；替换安装保留配置。

停用插件保留配置；在 WordPress 中删除插件会清除设置、凭证和状态。
